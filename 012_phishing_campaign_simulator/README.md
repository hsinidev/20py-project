# Automated Phishing Campaign Simulator

![Project Cover](assets/cover.png)

Developed by **HSINI MOHAMED**, this professional organizational audit tool evaluates organizational security awareness by simulating phishing attacks in a controlled, harmless environment.

## Key Features
- **Corporate Audit UI**: Fluent Design interface using PyQt6.
- **Local Intelligence**: Integrated Flask server for tracking engagement metrics.
- **Visual Analytics**: Interactive Matplotlib charts for vulnerability mapping.
- **Secure Storage**: AES-256 encryption for all campaign and target data.
- **Audit Reporting**: Professional PDF generation for executive review.

## Tech Stack
- **Frontend**: PyQt6 (Qt 6.6+)
- **Backend**: Flask (Observer Server)
- **Data**: SQLite + Cryptography (AES)
- **Charts**: Matplotlib
- **Reporting**: FPDF2
