# HOW TO USE: Generative Sentiment & Framing Matrix

![Screenshot](asset/1.PNG)

## 1. Setup
### Prerequisites
- Python 3.12+
- Kivy / KivyMD

### Installation
```bash
pip install -r requirements.txt
```

## 2. Operation
1. **Launch the Matrix**:
   ```bash
   python main.py
   ```
2. **Analysis Workflow**:
   - **Input Text**: Paste the generated content or URL to analyze sentiment framing.
   - **Calculate Matrix**: Click the analysis button to process the text.
3. **Visual Feedback**:
   - **Sentiment Grid**: View how the content is "framed" (e.g., Optimistic vs. Skeptical).
   - **Framing Bias**: Identify subtle linguistic patterns that influence search engine perception.

## 3. UI Theme
The interface uses a **Neumorphic Dark** theme with Lavender and Charcoal accents.
