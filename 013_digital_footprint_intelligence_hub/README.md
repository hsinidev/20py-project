# Digital Footprint Intelligence Hub (Scalable Edition)

![Cover](asset/cover.png)

## 🕵️ Overview
**Digital Footprint Intelligence Hub** is a premium OSINT command center for mapping digital identities. Developed by **HSINI MOHAMED**, it leverages high-concurrency asynchronous scanning and automated Google Dorking to visualize a target's online presence in real-time.

## 🚀 Key Features
- **MASO Architecture**: Modular Asynchronous Service-Oriented design for maximum performance.
- **Interactive Graph Canvas**: Real-time relationship mapping with NetworkX-driven node physics.
- **Deep Account Discovery**: Scans 400+ platforms simultaneously using `aiohttp`.
- **Automated Dorking Engine**: Targets sensitive metadata, PDFs, spreadsheets, and open directories.
- **Dossier Generation**: One-click export to JSON, CSV, and formatted intelligence reports.
- **OSINT-Dark Aesthetics**: High-fidelity glassmorphism with CRT-scanline overlays.

## 🛠️ Tech Stack
- **UI**: Kivy, KivyMD
- **Logic**: Python 3.10+, aiohttp, BeautifulSoup4
- **Data**: SQLite3, NetworkX
- **Reporting**: ReportLab (Simulated)
