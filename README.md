## 🧠 Part 1: Generative Engine Optimization (GEO) & AI Intelligence

### 001. Omni-Engine Visibility Tracker
- **Folder:** [`001_omni_engine_visibility_tracker`](./001_omni_engine_visibility_tracker)
- **Description:** Industrial-grade application for tracking brand visibility and attribution across major Generative AI search engines (Gemini, Perplexity, SearchGPT).
- **Key Features:** Multi-LLM API querying, real-time attribution scoring, position tracking, interactive PyQt6 UI dashboard.

### 002. LLM Citation Integrity & Truth-Grounding Auditor
- **Folder:** [`002_llm_citation_integrity_auditor`](./002_llm_citation_integrity_auditor)
- **Description:** Clinical verification tool designed to audit AI-generated content for grounding accuracy and citation integrity.
- **Key Features:** Semantic vector similarity analysis, live web source verification, hallucination scoring, detailed PDF audit generation.

### 003. Perplexity Rank Flux & Volatility Monitor
- **Folder:** [`003_perplexity_rank_flux_monitor`](./003_perplexity_rank_flux_monitor)
- **Description:** High-speed tracking engine monitoring search result position fluctuations and volatility on Perplexity.ai.
- **Key Features:** "Trading-Floor" telemetry dashboard, real-time rank tracking, volatility index calculations, notification triggers.

### 004. Generative Sentiment & Framing Matrix
- **Folder:** [`004_generative_sentiment_framing_matrix`](./004_generative_sentiment_framing_matrix)
- **Description:** Advanced NLP visualization suite analyzing how AI models frame specific brands, topics, and public entities.
- **Key Features:** Framing matrix generation, brand bias detection, multi-model sentiment heatmaps, interactive visualization canvas.

### 005. Agentic GEO-Schema Architect
- **Folder:** [`005_agentic_geo_schema_architect`](./005_agentic_geo_schema_architect)
- **Description:** Autonomous tool for generating deeply nested, 100% valid JSON-LD schemas optimized for AI search engines.
- **Key Features:** Auto-extraction of entities from text, schema validation engine, JSON-LD exporter, rich-snippet previewer.

### 006. Cross-Model Persona Bias Simulator
- **Folder:** [`006_cross_model_persona_simulator`](./006_cross_model_persona_simulator)
- **Description:** Research-grade tool for detecting and measuring behavioral and cultural bias variations across LLM personas.
- **Key Features:** Persona matrix simulation, comparative response scoring, demographic bias tracking, CSV/JSON report exports.

### 007. Featured-Snippet Neural Optimizer
- **Folder:** [`007_featured_snippet_neural_optimizer`](./007_featured_snippet_neural_optimizer)
- **Description:** Agency-modern desktop application for optimizing web content to capture LLM-featured snippets.
- **Key Features:** Atomic Paragraph Deconstruction, snippet readability score, competitive gap suggestions, live content editor.

### 008. Entity Saliency & Relationship Mapper
- **Folder:** [`008_entity_saliency_relationship_mapper`](./008_entity_saliency_relationship_mapper)
- **Description:** 3D Knowledge Graph engine mapping brand entity relationships and calculating entity saliency scores.
- **Key Features:** Named Entity Recognition (NER), PageRank-based entity saliency calculation, interactive PyOpenGL / 3D web canvas.

### 009. AI Mention Velocity Ticker
- **Folder:** [`009_ai_mention_velocity_ticker`](./009_ai_mention_velocity_ticker)
- **Description:** Financial-terminal style application for tracking real-time mention velocity of brands in LLM outputs.
- **Key Features:** High-frequency data ticker, intent signal filter, mention volume acceleration metrics, customizable alerts.

### 010. Competitor Semantic Gap AI Analyst
- **Folder:** [`010_competitor_semantic_gap_analyst`](./010_competitor_semantic_gap_analyst)
- **Description:** Executive "War-Room" dashboard for identifying semantic citation gaps between your brand and market competitors.
- **Key Features:** Semantic gap discovery, citation share-of-voice analytics, tactical content roadmap generator.

## 🛡️ Part 2: Cybersecurity, OSINT & Enterprise Defense

### 011. Real-time Dark Web Leak Monitor
- **Folder:** [`011_dark_web_leak_monitor`](./011_dark_web_leak_monitor)
- **Description:** Enterprise security tool monitoring dark web Onion services for credential leaks, API key exposures, and domain mentions.
- **Key Features:** Tor network integration (Stem/SOCKS5), circuit rotation, regex threat pattern matching, breach notification engine.

### 012. Automated Phishing Campaign Simulator
- **Folder:** [`012_phishing_campaign_simulator`](./012_phishing_campaign_simulator)
- **Description:** Controlled security awareness platform for testing and training organizational resilience against phishing attacks.
- **Key Features:** Template builder, email campaign scheduler, click-through & credential capture telemetry (simulated), employee risk scoring.

### 013. Digital Footprint Intelligence Hub
- **Folder:** [`013_digital_footprint_intelligence_hub`](./013_digital_footprint_intelligence_hub)
- **Description:** OSINT command center for mapping an individual's or organization's digital footprint across public channels.
- **Key Features:** Async OSINT reconnaissance engine, Google Dork automation, username availability search, network graph builder.

### 014. Social Engineering Vulnerability Mapper
- **Folder:** [`014_social_engineering_mapper`](./014_social_engineering_mapper)
- **Description:** Strategic intelligence tool auditing an organization's publicly exposed employee hierarchy and attack surfaces.
- **Key Features:** Organizational chart scraper/builder, PII exposure analyzer, Spear-Phishing risk index rating, executive summary report.

### 015. Endpoint Security Policy Auditor
- **Folder:** [`015_endpoint_security_auditor`](./015_endpoint_security_auditor)
- **Description:** Production-grade system auditing workstation configurations against **CIS (Center for Internet Security) Benchmarks**.
- **Key Features:** Local registry & WMI inspection, CIS baseline compliance checking, automated fix recommendations, compliance report exporter.

### 016. Zero-Trust Identity Verification Suite
- **Folder:** [`016_zero_trust_identity_suite`](./016_zero_trust_identity_suite)
- **Description:** Enterprise authentication gateway enforcing multi-factor, biometric, and hardware-bound zero-trust controls.
- **Key Features:** OpenCV facial matching, TOTP MFA validation, AES-256 encrypted credential vault, audit trail database (SQLite).

### 017. Encrypted Communication Tunnel Manager
- **Folder:** [`017_encrypted_tunnel_manager`](./017_encrypted_tunnel_manager)
- **Description:** Advanced networking manager for creating and maintaining multi-hop encrypted SSH/TLS tunnels with automated Kill-Switch.
- **Key Features:** Multi-hop SSH forwarding, automated firewall rule injection, active bandwidth & latency telemetry, connection auto-healing.

### 018. Malware Sandbox Behavior Visualizer
- **Folder:** [`018_malware_sandbox_visualizer`](./018_malware_sandbox_visualizer)
- **Description:** Forensic application converting flat malware execution logs into an interactive 3D spatial process behavior graph.
- **Key Features:** Process execution tree visualization, API call sequence timeline, file system & registry modification mapper, risk rating engine.

### 019. Automated Compliance Audit Suite (GRC)
- **Folder:** [`019_compliance_audit_suite`](./019_compliance_audit_suite)
- **Description:** Governance, Risk, and Compliance (GRC) platform validating system state against ISO 27001, NIST SP 800-53, and GDPR frameworks.
- **Key Features:** Automated rule engine, multi-framework compliance scoring, gap analysis dashboard, PDF/Docx executive report generation.

### 020. Network Lateral Movement Detector (NDR)
- **Folder:** [`020_lateral_movement_detector`](./020_lateral_movement_detector)
- **Description:** Network Detection and Response (NDR) engine for detecting internal threat propagation, ARP spoofing, and privilege escalation patterns.
- **Key Features:** Raw packet sniffer (Scapy), dynamic network topology builder, suspicious authentication anomaly scoring, alert command center.

## 🚀 Quick Start & Installation

### Prerequisites
- **Python 3.10+**
- **Git**

### Installation

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/hsinidev/20py-project.git
   cd 20py-project
   ```

2. **Set Up Virtual Environment:**
   ```bash
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On Linux/macOS:
   source venv/bin/activate
   ```

3. **Install Dependencies for a Specific Project:**
   Each project contains its own `requirements.txt`. Navigate to the desired project folder and install dependencies:
   ```bash
   cd 001_omni_engine_visibility_tracker
   pip install -r requirements.txt
   python main.py
   ```
